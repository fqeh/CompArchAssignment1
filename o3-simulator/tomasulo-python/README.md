# Tomasulo Algorithm Simulation

This is the revised assignment simulator based on the supplied starter credited
to Qing (May 2017). See the [repository README](../README.md) for the input format,
implementation details, tests, and report.

```sh
cd code
python3 main.py
python3 main.py test_case.txt --issue-width 4
```

The default input path is resolved relative to `main.py`, so the script also works
when invoked from another directory. No external packages are required.
