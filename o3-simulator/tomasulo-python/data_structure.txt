Current data structures (see code/init.py and code/simulator.py)

Program: validated Config, Instruction list, initial registers, 64-word memory.
FP values: IEEE 754 binary32, rounded at input, arithmetic, and memory transfer.
Instruction: static word PC, opcode, destination, source registers, immediate, text.
Operand: ready value OR dynamic producer tag; first available cycle.
Entry: unique dynamic tag, Instruction, Operand list, stage timestamps, result,
       effective address, prediction, fault, commit/squash status.
ROB: deque of dynamic tags in program order, bounded by rob_entries.
RAT: architectural destination register -> newest live producer tag.
RS: per-class queues of waiting tags, bounded by configured capacities.
LSQ: load/store tags in program order; loads removed after receiving data,
     stores removed only after commit completes.
Execution: dynamic tag, FU class, inclusive end cycle.
Results: completion cycle, dynamic tag, computed value; one CDB winner per cycle.
MemoryAccess: tag, inclusive end cycle, store/forward flags and store/forward data.
BTB: eight tagged direct-mapped entries, each with target and one direction bit.
History: all issued Entry records, including committed and squashed occurrences.
