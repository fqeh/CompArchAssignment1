Program: Config, decoded Instruction list, initial register/memory dictionaries.
Config: per-unit RS count / EX latency / FU count, memory latency, ROB capacity,
        issue width (1--4, default 1).
Registers: R0..R31 and F0..F31. R0 is immutable zero.
Memory: dictionary of 64 words indexed by byte address (0, 4, ..., 252).
RAT: destination register -> latest unretired writer's unique dynamic tag.
ROB: Entry list in dynamic issue order; includes source Operand objects, result,
     effective address, branch prediction, fault and stage timestamps.
Operand: captured value or producer tag, plus cycle when the value became ready.
Reservation stations: waiting Entry lists for integer, FP add, and FP multiply.
Executing: Execution records with Entry and completion cycle.
LSQ: Entry list in program order; loads leave at MEM completion, stores at commit.
MemoryAccess: one active access (Entry, completion cycle, transferred value).
BTB: eight direct-mapped Prediction records (word-PC tag, target, one-bit outcome).
History: every issued Entry, retained after commit/squash for final timing output.

See code/model.py for dataclasses and code/simulator.py for processor ownership.
